# Solar Energy Forecasting Using Python

Predicts **tomorrow's approximate energy (Wh) from a small solar panel** and compares four models:
moving average, linear regression, decision tree and random forest. Every statistic is shown on a
Streamlit dashboard.

The data is open: four weeks of hourly NASA POWER data for Tiruchirappalli (3 to 30 August 2026),
converted to the output of a 5 W panel. The same code also runs on readings logged from the
prototype (a small PV panel, an INA219 sensor and an Arduino).

## Results in brief

| Setting (14-day walk-forward test, 17 to 30 Aug 2026) | Best model | MAE (Wh/day) | MAPE |
|---|---|---|---|
| Past output only | Linear regression | 1.99 | 9.1 % |
| Past output + cloud-cover forecast | Decision tree | 1.03 | 5.0 % |

Forecast for 31 August 2026: **24.1 Wh** (likely 21.4 to 26.7 Wh). Every number is in
`reports/results.json` and is regenerated by `python analysis.py`.

## Reproduce everything

```bash
python fetch_open_data.py
python fetch_open_data.py --start 2026-01-01 --end 2026-08-30 --tag extended
python clean_data.py
python clean_data.py --raw data/raw/nasa_power_hourly_tiruchirappalli_20260101_20260830_extended.csv --out-prefix extended
python analysis.py
```

The raw files are already included, so the first two commands are only needed for a fresh download
or another site or period (change `SITE_NAME`, `LATITUDE_DEG`, `LONGITUDE_DEG`, `STUDY_START` and
`STUDY_END` in `config.py`). NASA publishes hourly irradiance about two months after real time.

## Dashboard

```bash
python run.py
```

It opens at http://localhost:8501 on the open dataset. Tabs: daily generation, intraday patterns,
statistics, model performance, tomorrow's forecast and data. In the sidebar, **Use weather forecast
(cloud cover)** adds tomorrow's clear-sky irradiation and a cloud-cover value you type in (from any
weather app). Add `?tab=4` to the URL to open on the forecast tab.

Terminal version:

```bash
python forecast.py
python forecast.py --weather --cloud 60
```

## The dataset and cleaning

Source: NASA POWER hourly point API (CERES SYN1deg irradiance, MERRA-2 weather), no key needed.
Parameters: all-sky and clear-sky irradiance, clearness index, cloud amount, temperature, humidity,
wind and rainfall.

`clean_data.py` parses the header, builds timestamps (local solar time), removes duplicate hours,
inserts missing ones, replaces the -999 missing code, removes physically impossible values, sets
night-time irradiance to zero, fills short gaps (flagged in an `imputed` column), drops days with
more than 4 filled daylight hours, and converts irradiance G to panel power with the NOCT model:

```
T_cell = T_air + (NOCT - 20) / 800 * G
P      = P_rated * G / 1000 * (1 + gamma * (T_cell - 25)) * derate
```

with NOCT = 45 C, gamma = -0.4 %/C and derate 0.90. In the study window the only issue was 308
night-time -999 codes in the clearness index; on the eight-month file the script also removed five
hours of an impossible 990 mm/h rainfall reading. Counts are in `data/cleaned/data_quality_report.json`.

## How the forecasting works

Inputs known the evening before: energy 1 to 3 days earlier, 3- and 7-day means, 3-day spread,
yesterday's peak power and generating hours, a day index, and optionally tomorrow's clear-sky
irradiation and forecast cloud cover. Linear regression is ridge-regularised; the trees are kept
shallow because there are only a few dozen training rows. Evaluation is walk-forward: each of the
last 14 days is predicted using only the days before it. Predictions are capped at 0 to 1.3 times
the best day seen.

## Using your own panel

1. Wire the INA219 (panel + to VIN+, VIN- through a 7 to 10 ohm, 5 W resistor to panel -, SDA/SCL to
   A4/A5 on an Uno or GPIO21/22 on an ESP32) and flash `hardware/solar_logger.ino`.
2. Set your panel's rating in `PANEL_RATED_W` in `config.py`.
3. Log for 2 to 4 weeks:
   ```bash
   python serial_logger.py --port COM5
   ```
4. In the dashboard choose **Logged data (PV panel)**.

The moving average needs at least 4 complete days and the other models about 11.

## Limitations

The panel output is modelled from satellite irradiance (about 100 km cells), not measured. The test
covers one monsoon month, and the weather results assume a perfect cloud forecast.
